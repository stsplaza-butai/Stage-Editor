舞台図面エディター（くまもと森都心プラザ用）

配置図・客席図・舞台備品レイアウトを作成するための
HTMLベースの簡易図面エディターです。

想定環境
・Webブラウザ（Chrome / Edge 推奨）

ローカル実行するには以下のファイルを同じ場所に置いてください。

index.html

fabric.min.js

jspdf.umd.min.js

使い方
1. index.html をブラウザで開く
2. 図面を作成
3. JPG / PDF / JSON で保存

自動保存
30秒ごとにローカル内に自動保存されます。
うっかりブラウザを閉じてしまった時など、アプリを開いてすぐに「再開」を押せば復活。
（図面に変更がない場合は自動保存も休止します。）

※ 本ツールは、くまもと森都心プラザの舞台仕様を前提に作成されています。
必要に応じて改変・再利用してください。
