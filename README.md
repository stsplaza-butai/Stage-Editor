舞台図面エディター（くまもと森都心プラザ用）

配置図・客席図・舞台備品レイアウト・打合せ表を作成するための簡易エディターです。

想定環境
・Webブラウザ（Chrome / Edge 推奨）

ローカル実行するには以下のファイルを同じ場所に置いてください。

index.html

fabric.min.js

jspdf.umd.min.js

使い方
1. index.html をブラウザで開く
2. 図面を作成
3. JPG / PDF / JSON で保存

自動保存
30秒ごとにローカル内に自動保存されます。（変更がない場合は休止）
うっかりブラウザを閉じてしまった時など、アプリを開いて30秒以内に「再開」を押せば復活。

※ 本ツールは、くまもと森都心プラザの舞台仕様を前提に作成されています。
必要に応じて改変・再利用してください。
